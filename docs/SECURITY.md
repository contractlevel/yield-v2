# Security Policy

Yieldcoin v2 is under active development. There are no live deployments and no bug bounty program at this time.

## Reporting Vulnerabilities

Please report suspected vulnerabilities to:

`contractlevel@proton.me`

Include as much detail as possible, such as affected contracts, transaction or call examples, impact, reproduction steps, and any relevant logs or traces.

Please do not disclose suspected vulnerabilities publicly until the team has had a reasonable opportunity to investigate and respond.
